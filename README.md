# Face Mask Detection Demo

Detects faces and classifies them as with mask, without mask, or mask worn incorrectly.

Dataset: Face Mask Detection (andrewmvd, Kaggle), CC0 1.0. Model: MobileNetV2 fine-tuned.
Educational demo only, not for surveillance or real safety decisions.
